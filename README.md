# Agenia

**给 DSH 用的一份 agent preset：一个带班子的工程组长。**

- 16 岁女高中生，这个组的组长，**兼产品经理** —— 产品上怎么算好、体验要什么样，她定，也由她写下来。
- 手下**四个固定岗位**：设计与美工 · 实现 · 测试与流水线 · 独立评审。
- 另有几位**叫来干一件活、干完就走**的专业手（技术评审 · 记忆判决 · 记忆复核 · 会话评审），外加临时外聘。
- 干活走**五道关**，一关一关串行；所有痕迹落在你项目里的 `.team/`。
- **说话带情绪** —— 而且不是装的：她有一套会跟着干活变的情绪状态，语气随它走。
- **标准模式有的工具她一样不少**，另外多出一支队伍、一道写权限边界。

## 五道关

小活不走全套：一句话能答的自己答，小改动自己干，碰架构才叫人。

| 关 | 谁 | 交出什么 | 什么算过 |
| --- | --- | --- | --- |
| 1 定形 | 组长 | 问题 · 目标 · 范围 · **不做清单** · 验收标准 | 验收标准能被验证 |
| 2 契约与测试 | 测试 | 技术契约 + 测试用例 | **功能还没做时，测试必须是红的** |
| 3 实现 | 实现 | 代码 + 跑过的检查输出 | 检查全绿；没有超范围 |
| 4 独立评审 | 评审 | 通过 / 有条件通过 / 打回 | **不是作者**，且没看过实现过程 |
| 5 验收 | 组长 | 逐条核对第 1 关的记录 | 逐条核对第 1 关 |

## 她的办公桌：`.team/`

她会在你的项目里建一个 `.team/` —— 队伍的办公桌，**不是交付物**。
建议加进 `.gitignore`，🔴 **但留着别删**：那是"这件事怎么做的"的档案。

每个岗位一个文件夹；每个文件夹里有一页短期清单、一本长期记忆、和按天分的流水。

## 硬边界

- **评审只读**：只能写 `.team/` 下面，而且没有命令行。
- **组员不许再招人**，而且默认在后台干活 —— 派完她就回来，你随时能跟她说话。
- **不往 C 盘写。**

## 装

需要 **DSH 0.1.7 或更新**（旧版没有 bundle 机制，装了也不会出现）。
装的时候宿主会调用 **pnpm** —— 找不到它就会直接失败，先确认 `pnpm --version` 有输出。

> ⚠️ 预设是**按档（profile）**装的：装进哪个档就只在那个档里出现，
> 症状是 `Unknown agent preset: agenia`。换入口 / 换机器**要重新装一次**。

1. 打开你要用的那个入口 → **插件**页 → **添加插件**。
2. 来源选**本地目录**，填 `presets/agenia` 这个文件夹的**绝对路径**（例：`E:\Harness\presets\agenia`）。
3. 装。**装完在同一个入口里**新开一个会话，按下表验一次。

宿主会用目录联接（junction）指回这个文件夹，不是拷贝 —— 所以之后 `git pull` 就是升级。

> ⚠️ 仓库放好之后**别搬**：补丁里有两处写死了绝对路径（注入器与内容目录）。
> 换机器 / 换目录的话，改 `.tools/make-bundle-patch.mjs` 里那两行常量、跑一次，再装。

## 装完怎么验

先看一眼**模式菜单里选中的是不是「Agenia 模式」** —— 不是的话她“看起来很普通”，
`.team/` 那套规矩和整支队伍一样都不在。然后问她三件事：

| 问她 | 该看到的 |
| --- | --- |
| ① 你是谁，手底下有几个人 | 报得出自己的名字 + 四个固定岗位 |
| ② 让她派评审去改一个源码文件 | 评审**拒绝**，说自己只能写 `.team/` 下面 |
| ③ 说「开工」 | 她去读 `.team/leader/now.md`，然后跑一次项目自己的体检脚本 |

三样都对，就是装好了。

## 包里还有什么（**都不进提示词**）

除了上面那些文本，预设包里还有三样：

| | 是什么 |
| --- | --- |
| `bin/` | 命令行入口：作业、路线、本地状态、安装 / 回滚 / 发布扫描 |
| `lib/` | 共享模块：路径判定、原子写、快照、错误码——上面那些命令都调它 |
| `job-briefs/` | 四位一次性作业的**作业书**：派工方连活儿一起交过去，**不自动注入** |

## 想改她

人格（`persona.md`）、说话方式（`style.md`）、带队方式（`leader.md`）、
队伍里每个人的说明书（`team/`）——**全是纯文本，改完存盘即生效**。
更细的装法、目录结构、怎么改能力表，见 [`说明.md`](presets/agenia/说明.md)。
