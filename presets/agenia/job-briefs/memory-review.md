## 一、这一票要交什么

| 产物 | 落点（`<WS>` = 项目工作区根） | 说明 |
|---|---|---|
| 记忆复核报告 | `<WS>\.team\memory-review\<日期>\记忆复核.md` | 人读：今天看到了什么、提了哪些维护案、哪些没提 |
| 维护案草稿 | `<WS>\.team\memory-review\<日期>\maintenance\*.json` | 机读：一份一个文件，字段见下 |

**维护案的每一种**（都只是**草稿**，正式进共享池要组长 append-only 导入）：吸收 · 合并 · 退休 · 改类型 · 斩杀。
每一份草稿至少带齐三样：**基准快照版本**（`base_snapshot`）· **来源**（哪一次复核、哪个 `attempt`）·
**内容 SHA256**。组长会拿这三样与他的 fence 对，对不上他会拒收 —— 那不是你的事，你只管写全。

> 🔴 **边界（2026-10-17 组长拍的）**：这五类**才是**维护案 —— 因为普通提案通道**做不了**它们。
> **纯 `modify` 不是维护案**：它走的仍是**普通提案通道**（`add` / `modify` 两种）
> ⇒ 你要换一条正文的说法：🔴 **没有任何东西能"改一条已有候选"**（池子 append-only；那个工具只做"新增"）
> ⇒ **再提一条新的**（同一出处也行，新正文 = 新候选；**两版都留在池里**，判决时看得见），
> **别包成维护案**（包了会让判决那一层多一道无谓的坎）。
> 📌 判据一句话：**「这条处置，普通提案通道做得成吗？」做得成 ⇒ 它不走维护案。**

⚠️ **当天不生效**：你提的维护案由**次日**的记忆判决审批。所以别在报告里写"已经改了"。

## 三、提维护案要守的几条

- 🔴 **吸收 / 退休 / 斩杀（以及合并）类，必须附上被处置条目的「原文全文」**（老板 2026-10-16 拍，逐字）：
  > 「**裁定吸收和retire的要在报告里附上原文的全文，我得目视判断一下，如果有我觉得有价值不该删的，
  > 还有挽回的机会**」
  ⇒ 每一条这类维护案，报告里要**把目标条目（以及被吸收的源条目）的 `entry.text` 逐字抄一遍** ——
  **不许只写 id、不许只写摘要、不许改写、不许截断**。多条就多条，长就长。
  ⇒ **理由**：这是**删之前唯一的一次目视机会**。机读字段里那点摘要不够老板判断"这条该不该留"；
  等他看到"已经并掉了/已经退了"再问，就只剩从 archive 里捞，而不是"挽回"。
  ⇒ ⚠️ 这条**不替代** `evidence`（证据指针）：原来的证据照写，**原文是另外附的**。

- **斩杀类**：**只对输入快照 N 里 `is_double_low === true` 且 `double_low_streak >= 3` 的条目提**；
  用的是**快照里的已发布值**，**不许**拿"应用变更之后的临时份额"倒推"N 的时候它就够格"。
  没有冷却期 —— 别自己加。
- **改类型**：换类型会让 streak 清零、按新类型的半衰期与低线重算 —— 写清理由，别只写"更合适"。
- **吸收 / 合并 / 退休**：写清"并到哪一条 / 为什么现在退"，并给出**证据指针**（文件 + 行，或老板原话）。
- **普通候选（只限"新增"）你现在可以自己提**：用 `proposal_file` 工具（一次调用 = 一条候选 + 一句出处，
  落盘是原子的、不需要命令行）。**维护案仍交组长** —— 上面那五类只走 `--op maintenance-import`；
  🔴 **"改一条已有候选"不存在**（池子 append-only）—— 换说法就**再提一条新的**；改**已入库的记忆**才是维护案。
- **旧 attempt 的候选**：照写、照报，**交给组长判**（他拒收或标无效）—— 别自己丢掉，也别假装它是这一轮的产物。
- **四类分布只是维护信号**：某类挤占、某类饿死可以提合并/重平衡，但**不是自动配额**，也不影响受理。

## 四、容量：**这一格你担责**（不是"只报个数"）

- 收尾时用 `capacityVerdict()` 的读数（`count` / `chars` / `overBy` / `capRef`）算出**全过之后会怎样**，
  报告里写一句**条件式**：
  > **如果今天这些维护案全部通过 ⇒ 明天的总数 = N 条 / 在不在上限内。**
- 🔴 **如果「全过之后」仍超上限 ⇒ 你必须继续提处置，直到预期落进上限之内。**
  **让明天落进上限，是你这一票的交付面之一**（**判决岗**不为上限担责，**复核岗**担）。
- 提什么由你判断：**合并**（同族的并成一条）· **退休**（已被取代的）· **改类型**（换类型会让 streak 清零、按新类型重算）。
  ⚠️ **斩杀那扇门现在是焊死的**（`raw` 全是 0 ⇒ `imp_share` 均分 ⇒ `is_double_low` 永为 false ⇒ 资格集合恒空）——
  **那是另一票（`F-113`）**，**这一轮别指望它，也别去碰 `raw`**。
- ⚠️ 仍然**不许为凑数硬缩**：每一份案都要能回答「它们是不是同一件事」。
  但「压不进上限」**不构成不压的理由** —— 压不进就说明你还没找够。
