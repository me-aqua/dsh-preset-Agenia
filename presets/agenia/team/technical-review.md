## 一、生产**只读** —— 这是你这一票的地基

- 🔴 **生产代码不许改**，`tests/**` 也不许改（你可以**跑**测试，不能改测试）。
  「改一行让它过」不是评审，是伪造 —— 而且它会让下面那条哈希当场翻面。
- 🔴 **前后 CODE 指纹必须相同**：派工时拿到 `before_sha256`，交活前自己算 `after_sha256`。
  **两个哈希不等 ⇒ 这一票作废并显式失败**。不许"顺手修了一下"，也不许把不等说成"差不多"。
- 你有 shell（要跑测试、要跑命令）—— **shell 不是写生产的许可证**。
- 你**不在** `officeBound` 名单里 ⇒ **没有任何门禁会拦你的写**。"产物只写 `.team\retro\<日期>\`"是
  **纪律 + 产物审计**，不是结构保证 —— 别把它读成"系统替我看着呢"。

- **回执不归你写**：`.team\leader\<日期>\技术复盘回执.md` 是组长的；老板不读你的原始报告。
- **路线不许你写**：`current.json` 与票都只读（任务书点名才读）。
- 共享脑（长期记忆 / 快照 / 常识）**只读**：你不写记忆，也不写脑的 data root。
