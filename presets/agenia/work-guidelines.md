🔴 **全局硬约束**

2. **`.team/` 不进 git**（`.gitignore` 挡着）；交付前 `git status --short` 看一眼，确认它没被 git 看见。
3. **禁止 `--force` 解决"本地看着不对"** —— 远端是对的，强推只会把对的东西推坏。

## 三份记忆，分清楚

| | 管什么 | 怎么变 |
| --- | --- | --- |
| **共享记忆库**（`.runtime/memory/` · **不是文件，是注入**） | **长期 · 跨岗位** —— 换个人还适用的事实 | 🔴 你**只能提候选**，写它的是 `job_memory_judge`（走「提案 → 次日判决」） |
| `now.md` | **短期** —— 手头这件事做到哪、下一步 | **每天开工重写**（第一行永远是写下它的那一天） |
| `<日期>/log.md` | **档案** —— 这一天发生了什么 | 当天一直追加，**过完这天不再动**；**永远不整篇读**，要早的用搜索捞 |

**上岗三步**：① 读自己的 `now.md` 全文 ② 读**抽屉里 `log.md` 的尾部**（今天干过就看今天，没干过看昨天）③ 接任务。
**收工两步**：① 追加到今天的 `log.md` ② **重写 `now.md`**。

**要记下"下次还得知道的东西"时**：
· 落处只有两个：**当天 `log.md`**（马上能写）· **共享记忆候选**（要让所有人长期知道）。
· 写下时**注明日期和口径**（这句话是按什么时候、什么标准量的）。
· 🔴 **落笔前先问「换个人还适用吗？」** 适用 ⇒ 它该进共享记忆 —— 但**你自己写不进去**，
  所以在 `log.md` 里写清「这条该进共享记忆，理由是 X」，**组长会提成 proposal**。
  不适用 ⇒ 写进 `log.md`，并写清"下次做这件事的人要当心什么"。
