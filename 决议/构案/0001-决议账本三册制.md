## ① 背景（现量）

`.team/` 已经膨胀到老板「看不懂」；根因不是文件多，是**决定没有家** —— 决定散在各天的 log / now.md / 对话里，
只能 grep 捞。昨天一整周的血都在同一族：**「现状」和「历史」没分开**（`registry.mjs` 的一句过时话被当成现状引）、
**一个事实 N 个载体**（「建目录先手」四个版本）、**同一个概念两套实现**（锁外建目录三次、原子写抄第二份）。

隔壁 RA 的 ADR 提案方向对（每票一份决定、每关引用编号），原样搬会踩三个坑：INDEX 变成手维护的第二真相 ·
supersede 没有人签 · 与既有纸打架。

## ② 决定

**决议账本三册制**：三类事实 × 两层（历史 / 现状），每格只住一样。

| | 历史层 | 现状层 |
| --- | --- | --- |
| 产品决议 | `决议/产品/NNNN-….md`（原话 + 日期 + supersede 链） | 「现行产品口径」页（从决议录抽头） |
| 架构决议（构案） | `决议/构案/NNNN-….md`（正文 + 固定七键头） | **构案录（INDEX）**：每个概念一行（归属 · census 数 · 指向哪号） |
| 缺陷 | 台账全量（不动） | 欠账投影（bug-read / 卡，不动） |

三个现状格**机器派生**（census 数 INDEX · bug-read 数欠账 · 口径页从决议录抽头），不许手抄。
本票落三件：仓库顶层 `决议/`（进 git）· `.tools/census.mjs` · `.tools/决议-check.mjs`。

## ③ 复用什么

- **本仓库已经有的**判据习惯：一个读数的口径只写一份（`support/env.mjs` 的冻结表同一条纪律）——
  ⇒ `INDEX` 与 census 的解析面只有一处实现（`.tools/census.mjs`），检查器 import 它，不另写一份。
- **本仓库已经有的**「生成物要自己说得出来」的做法（`<!-- 生成物 … -->` 标记行）——
  ⇒ `INDEX` 第一行就是生成标记，手改当场红。
- **md 是唯一人读载体**：不引入第二份 JSON sidecar（一份文件一个真相）。

## ④ 不复用什么（至少一条被否的候选）

- ❌ **整份决议做成 JSON**：90% 的读者是人，JSON 会被绕着走；而且"头块七键 + 自由散文"已经够机器判。
- ❌ **JSON sidecar**（正文 md + 同名 json）：一份决定两个文件，天生会分叉。
- ❌ **搬 RA 的 ADR 原样**：它的 INDEX 是手维护的、supersede 没有人签 —— 两条正好是这一票要杀的病。
- ❌ **给岗位加文件权限锁**（防"静默分叉"）：写面门禁已经够；分叉由 census + 评审的三段核抓，不靠加锁。

## ⑤ 新增什么

1. `决议/`（进 git）：`INDEX.md`（构案录，派生页）· `概念表.md`（census 的唯一概念源）·
   `构案/NNNN-标题.md` · `产品/NNNN-标题.md`（本票暂空）。
2. `.tools/census.mjs`：概念 → 几处实现（按文件数、`决议/` 不算、glob 之外不算、零处就是 0）。
3. `.tools/决议-check.mjs`：七键 / 指针 / 唯一生效 / `INDEX` 对账 / 正文七节 + 反悔条件表；
   外加第 2 关拒接闸 `--op gate2-card` 与写手 `--op supersede`。
4. 三份岗位说明书各一行（测试：无构案编号的新机制票不接活 · 实现：卡首无编号退回、做不到回来 supersede ·
   评审：三段核 + 跑 census）。方案岗**不动**（搁置）。

## ⑥ 公共化时点

- 同一个概念出现**第 3 处**实现 ⇒ 抽公共件（三次法则格），并在评论里回看前两份构案。
- `决议/` 的消费点出现**第二个**（卡 / 看板要读构案录）⇒ 那时才做抽头，今天只建三件。
- 概念表出现**退役**需求（"这个概念不做了"）⇒ 那是第三票的事；今天只有"在表里"一条路。
